# 给这个助手写一个新技能

一个技能就是一个文件夹,里面放一个 `SKILL.md`:

    skills\
      my-skill\
        SKILL.md

把 `my-skill` 整个文件夹拷到程序目录下的 `skills\` 里,就装好了。没有安装命令,
也没有下载——**装技能 = 拷贝文件夹**。

## SKILL.md 的格式

开头是 frontmatter(用三条横线包住),然后是正文:

    ---
    name: my-skill
    description: 一句话说明"什么时候该用这个技能"
    ---

    # 正文

    具体怎么做,写多详细都行。

只有 `name` 和 `description` 会被放进系统提示。**正文只有在决定使用这个技能时
才会被读取**,所以正文可以写得很长、很具体,不用担心占用上下文。

## 写法要点

- `description` 要写**触发条件**,不是内容简介。比如写
  "当需要把 CSV 转成 Markdown 表格时使用",而不是 "CSV 相关工具"。
  模型只靠这一行决定要不要打开你。
- 正文里可以直接写步骤、检查清单、示例、注意事项。
- 需要参考大段资料时,可以同目录再放几个文件,让模型用 `read_file` 去读。
- 目录里不要放密钥。技能目录会和程序一起被拷来拷去。

## 限制(重要)

技能是**只读**的:模型能读技能目录里的任何文件,但**不能修改**。

技能**不能执行命令、不能联网**。如果技能里带了脚本,那脚本只是一份"说明书"——
模型读得懂它,但**不会运行它**。所以技能要写成"让模型照着做",而不是"让模型跑一下"。
