SelfAgent — 便携式多模型命令行助手
=====================================

把整个文件夹拷到U盘,插到任意一台联网的 Windows 电脑,打开 cmd 就能用。
目标电脑无需安装 Python、Node 或任何其他东西。


一、首次使用(每支U盘只需做一次)
------------------------------------------------

1. 打开 cmd,进入本文件夹所在的盘符和目录,例如:

      F:
      cd \agent

2. 录入 API Key(会先让你设置一个口令,再用它加密保存 Key):

      agent.bat --setup

   按提示输入服务商名(如 deepseek、anthropic、qwen、kimi、zhipu、doubao、
   openai、custom)和对应的 API Key。直接回车结束录入。


二、日常使用
------------------------------------------------

  交互式对话(多轮上下文):

      agent.bat

  单次提问:

      agent.bat "用一句话解释量子纠缠"

  指定模型:

      agent.bat -m claude "你好"
      agent.bat -m deepseek/deepseek-v4-pro "你好"
      agent.bat -m qwen "你好"

  从文件读取问题(管道):

      type question.txt | agent.bat

  输出重定向到文件(纯文本,不含颜色代码):

      agent.bat "写一段排序代码" > out.txt

  其他参数:

      --list            列出已配置的服务商与模型
      --setup           录入或更新 API Key
      --no-history      本次不写历史记录
      --no-color        禁用彩色输出
      --show-thinking   显示模型的思考过程
      --dir 路径        指定文件工具的工作目录(默认=当前目录)
      --allow-write     单次模式下允许写文件(见第五节)
      --no-tools        完全关闭文件读写工具
      --no-skills       本次不加载 skills\ 里的技能(见第六节)
      --version         版本号


三、交互模式内的命令
------------------------------------------------

   /clear           清空当前上下文
   /compact         把当前对话压缩成摘要以省 token(会调用一次模型)
   /resume [序号]   列出历史会话,或载入某个继续对话
   /forget [序号|区间|all] 删除历史会话记录(先列清单,再问一次才删)
   /retry           重发上一条问题(网络抖了的时候用)
   /model [名称]    查看或切换模型
   /usage  /cost    查看本次会话的 token 用量与对话轮数
   /status          一屏看清当前状态
   /doctor          自检:配置、Key、网络、工作目录、技能
   /config          显示 config.json 路径
   /name <名字>     改界面显示名(写入 config.json,立即生效)
   /theme <上> <下> [强调色]  改渐变配色,例:/theme #22d3ee #a855f7
   /persona <文字>  一句话角色定位(写入 config.json,下次启动生效,用 - 清空)
   /instructions <文字> 附加要求(写入 config.json,下次启动生效,用 - 清空)
   /default-model <服务商/模型> 设为默认模型并保存
   /skills          查看已安装的技能
   /tools [on|off|readonly] 开关文件读写工具,或切成只读
   /dir [路径]      查看或切换工具的工作目录
   /undo            撤回上一次文件修改(会先给你看差异再问)
   /audit           本次会话改过哪些文件
   /export [路径]   把当前对话导出成 Markdown
   /key <服务商>    录入或更新某个 Key
   /keys            查看哪些服务商已配置 Key
   /help            帮助
   /exit            退出

   Ctrl+C 中断当前回答,Ctrl+D 退出。

   输入的地方夹在上下两条横线之间,横线颜色和启动图案一样是从青到紫的渐变,
   下面还有一行暗色提示,内容随你正在输入的文字实时变化:

        ────────────────────────────
        ❯ 在这里打字
        ────────────────────────────
          / 命令   Enter 发送   Ctrl+C 退出

   一输入 "/" 就列出常用命令;继续打字会按前缀收窄,例如输入 "/mo" 只剩
   "/model 查看/切换模型";命令打完整后显示它的说明。不是命令的普通文字则
   只提示发送/退出快捷键。

   横线的宽度会跟着你输入的字数实时伸缩:字越多线越长,删字时随之变短,缩到
   一个最小宽度(8 列,刚好放下"❯ "和光标)后不再缩。超出终端宽度的超长一行
   会在两条线之间横向滚动(光标跟随),不会把线撑破。粘贴多行文本时横线按行数
   下移、多出来的行与文字左对齐;删掉换行后立即缩回,横线不会跟着文字一起被
   删掉。输入框没有左右竖线;那行提示只在输入时出现,提交后自动清除,不会留在
   对话记录里往下滚。

   这个输入区由 prompt_toolkit 接管终端来画,每一次按键都重绘,所以宽度能跟着
   内容走;中文输入法也照常可用。若运行环境装不上它或接管失败,会自动退回
   上面那个静态渐变版本,功能不受影响。

   横线和这个提示符都只在真正的终端里出现,颜色都取自启动图案的渐变。
   在不认 ANSI 的老控制台上会自动退回成朴素的"你> ",不会打印乱码。


四、文件说明
------------------------------------------------

   agent.bat        启动脚本(cmd 里运行这个)
   agent.exe        主程序
   _internal\       程序依赖,不要删除
   config.json      明文配置:服务商地址、模型名、默认模型等,可直接用记事本修改,
                    也可在交互模式里用 /name、/theme、/persona 等命令改
   secrets.enc      加密后的 API Key,没有口令无法读取
   history\         对话历史(.jsonl,每行列一条,可直接用文本工具查看)
   skills\          技能目录,一个技能一个文件夹(见第六节)。可以整个删掉

   history\ 和 skills\ 都在程序文件夹里,所以它们跟着U盘走:换台电脑插上U盘,
   用 /resume 就能接着上次的对话继续,技能也还是那几个。

   会话记录会越攒越多。清理用 /forget:不带参数先看清单,/forget 3 删第 3 个,
   /forget 2-6 删第 2 到第 6 个,/forget all 全删(序号和区间可以混着写,
   如 /forget 1 3-5)。删除不可撤销,所以它每次都先把要删的文件名和总大小列出来,
   再问一次(默认是 N)。当前这次会话自己的记录不会被删——它还在写。


五、让它动手改文件
------------------------------------------------

  程序带有文件读写工具。工作目录就是你执行 agent.bat 时所在的目录:

      D:\> cd D:\myproject
      D:\myproject> X:\agent\agent.bat

  这时它的工作目录是 D:\myproject,可以读里面的文件、帮你改代码。
  工作目录之外的路径(包括 ..\ 和指向外部的符号链接)一律拒绝。

  写入前一定会先把差异列出来,敲 y 才落盘:

      模型请求编辑:D:\myproject\src\app.py
      --- D:\myproject\src\app.py (原)
      +++ D:\myproject\src\app.py (新)
      -    timeout = 30
      +    timeout = 60
      允许编辑? [y/N]

  单次模式默认只读,脚本调用不会意外改文件。确实要在脚本里写文件时:

      agent.bat --allow-write "把 a.txt 里的 foo 全部改成 bar"

  注意:加上 --allow-write 就代表一次性授权,之后不再逐个确认——单次模式
  没有终端可以提问。想换工作目录用 --dir 路径,彻底关掉工具用 --no-tools。

  能不能用工具还取决于服务商。config.json 里每个服务商有一个 "tools" 开关;
  遇到不支持工具调用的端点,程序会自动降级成纯文本对话并给出提示,不会中断对话
  (Kimi 和智谱的流式工具调用有已知问题,默认已关)。

  改错了可以撤回。本次会话里每一次成功写入都会记下改前的内容(最多 20 条):

      /audit           一屏看清这次会话改过哪些文件
      /undo            撤回上一次(撤销本身也要你确认)

  在别人的电脑上尤其有用:干完活先 /audit 交代清楚,发现改坏了再 /undo 往回退。
  撤销"新建的文件"就是把它删掉,这一步同样会先问你。

  凭据类文件默认拒写:.env、secrets.enc、id_rsa、*.pem、*.key,以及 .git/、
  .ssh/、.aws/、.gnupg/ 这几个目录下的任何路径。这不是安全边界(沙箱才是),
  但"模型顺手整理了代码"和"模型动了你的凭据"是两种性质完全不同的事。
  确实需要时把 config.json 里 "tools": {"protect": false} 关掉。

  /tools readonly 是介于开与关之间的档:模型能看能搜,但一个字都改不了。
  在别人的电脑上,这是"让模型先摸清情况"的合适模式。


六、项目约定(AGENTS.md)
------------------------------------------------

  技能跟着U盘走,说的是"你"的习惯。项目约定跟项目走,说的是"这个项目"的要求。

  在工作目录根下放一个 AGENTS.md,程序启动时自动读进系统提示:

      D:\myproject\AGENTS.md

      本项目用 tabs 缩进,注释一律用中文。
      修改 database.py 前先读 schema.md。
      不要动 migration/ 目录下的文件。

  没有这个文件就什么都不加,不影响任何行为。文件名可以在 config.json 的
  "context" 段里改,也支持子路径(如 ".agent/CONTEXT.md");内容超长会截断并在
  结尾标注。用 /status 能看到它到底有没有被读到。


七、技能(Skill)
------------------------------------------------

  技能是给模型看的"说明书",放在 skills\ 里,跟着U盘走——插到哪台电脑都在。

  装一个技能:把技能文件夹整个拷进 skills\ 即可。没有安装命令,也不联网下载。

      skills\
        write-a-skill\
          SKILL.md
        my-skill\
          SKILL.md

  每个技能文件夹里必须有一个 SKILL.md,开头是 frontmatter(三条横线包住):

      ---
      name: my-skill
      description: 一句话说明"什么时候该用这个技能"
      ---

      # 正文

      具体怎么做。

  它是怎么工作的:启动时只读每个 SKILL.md 的 name 和 description,拼进系统提示;
  模型觉得某个技能跟当前任务相关,才会用 read_file 去读它的正文。所以正文写多长
  都行——没被用到就不占上下文。

  description 要写"什么时候用",不是"这是什么"。模型只靠这一行决定要不要打开它。

  随包附了一个示例技能 skills\write-a-skill\,讲的就是怎么写技能,不需要可以直接删。
  用 /skills 可以查看已装了哪些;agent.bat --list 也会列出来。

  几点限制,都是刻意设计的:

   · 技能是只读的。模型能读技能目录里的任何文件,但不能改、不能新增、不能删。
   · 技能不能执行命令、不能联网。技能里带脚本的话,脚本只是一份说明书——模型读得懂,
     但不会运行它。
   · 工作目录之外的其它路径依然一律拒绝,技能目录是唯一的例外,而且只读。
   · --no-skills 可临时不加载;config.json 里 "skills": {"enabled": false} 可永久关掉。


八、改成你自己的服务商 / 中转地址
------------------------------------------------

  名字、角色和配色也可以不改文件,直接在交互模式里用命令完成:

      /name 小助手
      /theme #ff6b6b #f59e0b
      /persona 严谨的代码审阅助手
      /instructions 回答先给结论,再给理由
      /default-model deepseek/deepseek-v4-pro

  /name 和 /theme 立即生效;/persona、/instructions 会写进系统提示,下次启动
  生效;/default-model 同时切换本次会话。所有命令都写回 config.json(先写临时
  文件再替换,避免U盘拔出一半写坏),换台电脑插上U盘仍然有效。手动用记事本
  改文件也仍然可以,两种方式改的是同一份配置。

  agent 段落控制名字和角色(对应上面的 /name、/persona、/instructions):

   "agent": {
     "name": "SelfAgent",   // 界面显示名,也用来告诉模型自己叫什么
     "persona": "",         // 一句话角色,例如"严谨的代码审阅助手"
     "instructions": ""     // 附加要求,可以多行
   }

   名字会出现在启动画面、agent.bat --version 和 /export 的标题里。persona 和
   instructions 会追加到 generation.system 后面,顺序是:基础提示 → 身份 →
   技能 → 项目约定。三项都保持默认(空)时,不会给模型多发任何内容。

  ui.theme 控制装饰色(启动渐变、输入框、spinner、工具活动前缀;也可以用
  /theme 上色 下色 [强调色] 直接改):

   "ui": {
     "theme": { "top": "#22d3ee", "bottom": "#a855f7", "accent": "#22d3ee" }
   }

   颜色写 #RRGGBB(也接受 RRGGBB 和 #RGB)。top/bottom 是渐变的上下两端,
   accent 是光标标记、spinner 和工具调用前缀的颜色;accent 省略时跟随 top。
   写错会直接报错并指出字段名,不会静默忽略。想换成暖色可以试:
   top #ff6b6b、bottom #f59e0b、accent #ffb86b。
   警告黄、错误红、差异里的增绿删红是语义色,不跟主题变。

  config.json 里的 providers 段落,每一项长这样:

   "deepseek": {
     "kind": "openai",
     "base_url": "https://api.deepseek.com",
     "models": ["deepseek-v4-flash", "deepseek-v4-pro"],
     "tools": true
   }

  - kind 只取 "openai" 或 "anthropic" 两种。绝大多数服务商(含各类
    中转、自建、国产模型)都兼容 "openai"。
  - base_url 改成你的地址即可,改完重启程序生效,不需要重新打包,
    也不需要输入口令。
  - tools 表示这家是否支持工具调用(即第五节的文件读写)。默认 true;
    如果你的端点报错说 tools 不被支持,改成 false 即可。
  - 想加一个全新的服务商,复制一段、改个名字放进去就行,然后用
    agent.bat --setup 或 /key 给它录 Key。

  tools 段落控制文件工具的行为:

   "tools": {
     "enabled": true,
     "workspace": null,        // null = 启动时所在目录
     "confirm_writes": true,   // false 则不再逐个确认(不建议)
     "protect": true,          // false 则允许改 .env、*.pem 等凭据类文件
     "max_steps": 10,          // 单轮最多几回工具调用
     "max_read_bytes": 262144
   }

  context 段落控制项目约定(见第六节):

   "context": {
     "enabled": true,
     "file": "AGENTS.md",      // 相对于工作目录,可以是 ".agent/CONTEXT.md"
     "max_chars": 8000         // 超长截断,避免项目说明吃掉整个上下文
   }

  generation 段落里,retries 表示请求失败后重开几次:

   "generation": { "max_tokens": 8192, "retries": 2, ... }

  只重试"还没吐出任何字"的请求——连接断了、被限流(429)、服务端 5xx 才会重试,
  而且指数退避。一旦已经流出内容就不再重试,否则你会看到同一段话出现两遍。
  配置成 1 等于不重试。

  ui 段落控制界面表现:

   "ui": {
     "stream": true,           // 流式输出
     "color": true,            // 彩色输出(仅终端生效)
     "show_thinking": false,   // 显示思考过程(同 --show-thinking)
     "splash_animation": true, // 启动图案动画;嫌启动慢可改成 false
     "spinner": true,          // 等模型开口时的"思考中"提示符
     "prompt_box": true,       // 输入处的上下两条渐变横线;不想要就设 false
     "theme": {                // 装饰色,见本节开头
       "top": "#22d3ee",
       "bottom": "#a855f7",
       "accent": "#22d3ee"
     }
   }

  启动图案默认是动态的:先在终端里逐行浮现,再让一道光晕沿 ∞ 扫过,最后停在
  原来的静态渐变上。三点说明:

   · 只有在真正的终端里才动画。输出被重定向或走管道时不动画,`agent "q" >
     out.txt` 拿到的仍然是干净的纯文本。
   · 若目标机器无法开启 ANSI(VT)处理,会自动降级成"只逐行浮现",不会把转义
     序列当乱码打印出来。
   · 动画全程约一秒。想更快启动就把 splash_animation 设为 false。
   · spinner 是等模型开口时的"思考中"提示符,规矩和动画一样:只在真正的终端里
     出现,而且终端要认 ANSI(VT);管道输出里不会混进任何提示符。不想要就设为
     false。
   · prompt_box 是输入处上下两条渐变横线,同样只在真终端 + 认 ANSI 时出现。
     横线在 GBK 控制台上没问题(GBK 收得下 ─),只有 ❯ 会退成 >。
     横线由 prompt_toolkit 接管终端来画,宽度随你输入的字数实时伸缩(字多则
     线长、删字则线短),超长一行在两条线之间横向滚动,不再漏到线外。横线下方
     的暗色提示也随输入实时变化:空行显示快捷键,"/" 开头按前缀列出匹配的命令,
     命令完整后显示说明;提交或 Ctrl+C 后自动清除,不留在对话里。拖动窗口底边
     改变高度后,输入框会像底栏一样贴住新的底部,而且上面已显示的对话会跟着它
     一起移动——拉高时旧内容整体下移(终端有滚动区时改为向上露出更多历史),
     拉矮时内容向上收、输入框始终完整可见,文字和输入框不会被一道空白隔开。
     粘贴多行文本
     时横线按行数下移、续行与文字对齐,删行后立即缩回。若 prompt_toolkit
     不可用,自动退回静态渐变版本(静态版本没有那行提示)。

  aliases 段落可以给常用模型起短名,例如:

   "claude": { "provider": "anthropic", "model": "claude-opus-4-7" }

  之后 agent.bat -m claude 就能直接用。


九、安全须知
------------------------------------------------

  · secrets.enc 用的是口令派生的密钥加密(PBKDF2-HMAC-SHA256,60 万次
    迭代 + AES-128-CBC + HMAC 校验)。口令本身不保存在任何地方,忘了就
    只能删掉 secrets.enc 重新录入。
  · 口令每个会话需要输入一次。这是有意的取舍:U盘会丢,明文存 Key 等于
    把账号余额一起送人。
  · 如果U盘和程序文件一起被人拿走,他们拿到的只是一个需要口令才能打开的
    密文文件。口令请自己记住,不要写在U盘里。
  · 文件工具的限制是刻意设计的:只能在指定目录内读写、不执行命令、不联网、
    每次写入都要确认。防的是"模型读到某个含有恶意指令的文件,转头去改别的
    东西"——这个程序可能插在别人的电脑上。
  · 技能目录是这套限制里唯一放宽的一处,而且只放宽了"读":模型能读 skills\,
    但写不进去。所以技能本身不构成新的攻击面——技能里的文字和别的文件一样,
    只能影响模型说什么,不能让模型多动一个文件。
  · 但只要你按下 y,模型就能在授权目录内任意改动文件。对它提的修改不满意时,
    在确认那一步直接回车(默认就是 N)远比事后回滚省事。


十、已知限制
------------------------------------------------

  · 部分公司/学校的电脑有安全策略,可能拦截任何未签名的程序。若遇到
    "Windows 已保护你的电脑",点"更多信息 → 仍要运行";若被企业策略
    直接阻止,则无法绕过,需联系该机器的管理员。
  · U盘存取速度较慢时,启动和数据写入会比本地磁盘慢,程序已按"写入失败
    就静默降级"处理,不会因此中断对话。
  · 目标电脑必须能访问对应服务商的接口地址。国内网络中,OpenAI 与
    Anthropic 官方接口通常需要代理;DeepSeek、通义、Kimi、智谱、豆包
    可直接访问。
  · 工具调用需要服务商支持。不支持的端点会自动降级为纯文本对话并提示;
    也可以直接在 config.json 里把该服务商的 "tools" 设为 false。
  · /undo 只对本会话有效,而且只记最近 20 次写入——重启程序后旧的记录就没了。
    所以它防的是"刚改完就发现不对",不是长期备份。
  · 输入的上下两条横线在能接管终端时(默认)随字数实时伸缩,超长一行在两条线
    之间横向滚动,下方提示随输入实时更新;接管失败才退回"读完之后重绘压缩"的
    静态版本(没有提示行)。两种情况下提交给模型的内容都是完整原文,显示压缩/
    换行不影响实际发送的内容。
  · 项目约定(AGENTS.md)要在工作目录里能读到;用 --dir 指向别的目录时,
    读的就是那个目录下的 AGENTS.md。


十一、重建(仅在修改了源码之后需要)
------------------------------------------------

在装了 Python 的开发机上,于项目根目录运行:

      python build.py

产物就是 andist\agent\ 这一个文件夹,直接整个拷到U盘即可(agent.bat、
agent.exe、_internal\、config.json 都在里面)。首次运行后,这个文件夹里
会多出 secrets.enc 和 history\,以后重拷时一并带上,否则 Key 要重录。

重新构建不会动你已经积累的东西:secrets.enc、history\、skills\ 会先被挪开、
构建完再放回去。仓库里的 skills\ 里有示例技能,会被拷进产物;你自己的技能
优先级更高,不会被示例覆盖。
